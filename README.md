
# DroneRoute AI 🚁

ML-based autonomous drone navigation system using 
KNN Classification + BFS Path Planning + Microsoft AirSim

## Features
- KNN classifier for safe/unsafe and caution zone detection
- BFS algorithm for shortest path planning  
- 3D simulation in Microsoft AirSim
- Academic Score: 28/30

## Tech Stack
Python | Scikit-learn | Matplotlib | AirSim | Jupyter Notebook
